# 设计作息管理 App｜开发上下文

> 本文件根据当前可检索到的“设计作息管理 app / AI生活导师”相关上下文整理，用于后续继续开发时恢复项目背景。

## 1. 项目起因

这是一个帮助用户管理作息、减少无意识刷手机、恢复日常节奏的 App 项目。用户此前已经开始做原型，并实现了在打开小说/短视频相关应用时触发提醒的早期版本。

## 2. 核心问题

用户观察到自己在目标感不足时容易出现：起床后长时间刷手机、拖延待办事项、作息推迟、吃饭不规律等问题。项目希望把“外部结构”与“即时提醒”结合起来，让用户更容易进入自己计划好的节奏。

## 3. 已有原型思路

- 监测用户打开小说、短视频等容易造成连续消耗时间的应用。
- 在检测到相关使用行为后弹出提醒。
- 目标不是单纯禁止使用，而是在关键节点增加一次“打断”，帮助用户重新选择。
- 原型目前偏 Android 侧。

## 4. 已有文件

项目历史文件中存在 `RhythmGuardian-android-source.zip`，创建于 2026-09-15，说明已有 Android 源码包。

## 5. 产品方向

后续设计可以围绕“作息管理 + 屏幕使用行为干预”展开，而不是单纯做传统闹钟或待办清单。重点包括：

1. 用户设定一天的重要时间锚点，例如起床、吃饭、健身、学习、睡觉。
2. 根据当前时间与用户行为做轻量提醒。
3. 对短视频、小说等高风险连续消费行为进行及时打断。
4. 提供当天节奏的可视化反馈。
5. 尽量减少复杂设置，让 App 本身承担一部分管理工作。

## 6. 使用场景

典型场景包括：

- 早晨醒来后避免躺在床上刷手机。
- 工作/学习期间发现自己开始进入连续娱乐使用状态时及时提醒。
- 晚饭后、睡前避免被短视频/小说拖延到深夜。
- 当一天计划失控后，帮助用户快速重新建立下一段时间的节奏，而不是因为一次失误放弃全天。

## 7. 开发原则

- 优先解决一个明确行为问题，再逐步扩展功能。
- 提醒要尽量短、明确、可行动，避免频繁打扰。
- 保持本地优先，尽量减少不必要的数据收集。
- 后续功能以真实使用反馈驱动。
